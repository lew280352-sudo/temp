## ขั้นตอนเปิดความสามารถที่ยังขาด

1. **Groq:** คีย์ที่ส่งในแชตถือว่าเปิดเผยแล้ว ให้เพิกถอนที่ [GroqCloud Keys](https://console.groq.com/keys) สร้างคีย์ใหม่ และใส่ `GROQ_API_KEY=...` ใน `.env` บนเครื่องเท่านั้น จากนั้น restart ด้วย `npm.cmd start` ห้ามส่งคีย์ใหม่ในแชตหรือ push ขึ้น Git
2. **ราคาย้อนหลัง/แนวโน้ม:** สมัครคีย์ฟรีที่ [Alpha Vantage](https://www.alphavantage.co/support/#api-key) แล้วใส่ `ALPHAVANTAGE_API_KEY=...` ใน `.env` และ restart เมื่อเปิดหน้า AI Insights จะดึงราคาย้อนหลังของหุ้นที่เลือกอย่างมากหนึ่งครั้งต่อ 24 ชั่วโมง ถ้าผลทดสอบไม่ผ่านจะแสดงว่า “ยังไม่แสดงสัญญาณ”
3. **ข่าว:** Finnhub key ที่ตั้งไว้ใช้กับข่าวการเงินได้ ขณะเซิร์ฟเวอร์ทำงานจะดึงข่าวตามรอบ และแต่ละข่าวบอกชื่อสำนักและลิงก์จริง ฟีด Federal Reserve สองรายการดึงอัตโนมัติเมื่อผู้ใช้เลือก URL ที่ตรงรายการอนุมัติเท่านั้น URL อื่นยังเป็นบุ๊กมาร์ก
4. **MFA:** เครื่องที่พัฒนานี้สร้างคีย์เข้ารหัสใน `.env` แล้ว เครื่องอื่นให้รัน `node scripts/configure-mfa.mjs` และ restart จากนั้นเข้าเมนูการแจ้งเตือน → บัญชีและความปลอดภัย → เปิด MFA เก็บรหัสกู้คืนบัญชี หากย้ายเครื่องหรือกู้ฐานข้อมูลต้องเก็บ `MFA_ENCRYPTION_KEY` เดิมด้วย
5. **Web Push:** เครื่องที่พัฒนานี้สร้าง VAPID keys ใน `.env` แล้ว เครื่องอื่นให้รัน `node scripts/configure-push.mjs` และ restart จากนั้นเข้าเมนูการแจ้งเตือน → เปิด Push บนอุปกรณ์นี้ แล้วกดส่งทดสอบ ทำงานเฉพาะขณะเซิร์ฟเวอร์เปิด; มือถือจากภายนอกต้องมี public HTTPS URL ก่อน
6. **ยืนยันอีเมล:** ตั้ง `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM` และ URL ต้นทางให้ตรงอุปกรณ์ที่เปิดลิงก์ จึงจะส่งลิงก์ยืนยันได้ ไม่เก็บ token ดิบในฐานข้อมูล ปัจจุบันยังไม่มีบัญชี SMTP และไม่ได้บังคับให้ทุกบัญชียืนยันก่อน Login
7. **Security audit ภายนอก:** ยังไม่ได้ว่าจ้างหรือรับรายงานจากผู้ตรวจอิสระ การทดสอบในโปรเจกต์และ `npm audit` เป็นเพียงการตรวจภายใน ไม่ใช่ใบรับรองความปลอดภัยสำหรับเปิดสาธารณะ

แผน Alpha Vantage แบบฟรีมีโควตา ข้อมูลรายสัปดาห์ถูกปรับ split/ปันผลแล้ว แต่ราคาในโหมดนี้ไม่ใช่ราคาซื้อขายล่าสุด ผล AAPL ย้อนหลัง 5 ปีของกฎ 4 สัปดาห์ยังไม่ชนะ baseline จึงไม่แสดงสัญญาณคาดการณ์ โมเดลทดลองนี้ยังไม่ควรใช้ตัดสินใจซื้อขาย ข้อมูลข่าวผ่าน Finnhub ต้องตรวจสิทธิ์การนำไปแสดงต่อก่อนเผยแพร่แอปสู่สาธารณะ
