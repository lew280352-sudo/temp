# จุดบอดของ StockLens 0.5

**อัปเดต 0.6.0:** AI รองรับ GroqCloud Free Plan/Qwen 3.8 27B ออนไลน์ และ Ollama/Qwen3 8B ในเครื่อง ตาม [LOCAL_AI.md](LOCAL_AI.md)

สถานะนี้เป็นแอปที่รันบนเซิร์ฟเวอร์จริงในเครื่องและเตรียม PWA แล้ว ยังไม่ใช่บริการออนไลน์ที่เปิดให้ทุกคนใช้

| ส่วน | ทำงานแล้ว | ยังขาด |
| --- | --- | --- |

| ค้นหา | 12 บริษัทสหรัฐฯ ชื่อไทย/อังกฤษ พร้อม IR และ SEC links | ทุก ticker / ข้อมูลบริษัทและงบการเงินแบบอัตโนมัติ |

## ข้อจำกัดที่กระทบการใช้งาน

- หัวข้อ RSS เป็นข้อมูลจากบริษัทเอง มีความลำเอียงได้ ไม่เท่ากับข่าวอิสระหรือสรุปทางการเงินที่ตรวจสอบแล้ว Feed อาจเก่า เปลี่ยน URL ปิดบริการ หรือบล็อกเซิร์ฟเวอร์ได้
- AI เห็นเฉพาะหัวข้อ แหล่งข่าว และเวลา ไม่เห็นบทความเต็ม งบการเงิน หรือราคา ผลสรุปจึงอาจพลาดบริบท ต้องเปิดลิงก์ต้นฉบับตรวจสอบ และไม่ควรใช้ตัดสินใจซื้อขายเพียงอย่างเดียว
- เวลา “ดึงสำเร็จ” เป็นเวลาตรวจฟีด ไม่ใช่อายุข่าว อ่านเวลาเผยแพร่ด้วย อัปเดตทุก 15 นาทีไม่ได้หมายความว่ามีข่าวใหม่ทุก 15 นาที
- รองรับ ingestion เฉพาะ 3 URL ที่กำหนดในโค้ด ผู้ใช้เพิ่มเว็บไซต์อื่นได้ในฐานะบุ๊กมาร์กเท่านั้น เซิร์ฟเวอร์ไม่ fetch URL ตาม input เพื่อหลีกเลี่ยง SSRF
- ไม่ใช้ราคาปลอมแทนราคาที่ขาด ไม่มีผลกำไร/ขาดทุนหรือความน่าจะเป็น AI ที่แต่งขึ้น
- SQLite และ scheduler ออกแบบสำหรับ instance เดียว ต้องใช้ persistent volume ถ้าโฮสต์หยุด/sleep จะไม่มีการดึงข่าวจนกลับมาทำงาน
- Rate limiter อยู่ใน memory และนับตาม socket IP ไม่เชื่อ X-Forwarded-For เมื่ออยู่หลัง reverse proxy ผู้ใช้จะถูกนับรวม ต้องเตรียม rate limit ที่ edge และกำหนด trusted proxy ก่อนเปิดกว้าง
- รหัสกู้คืนเป็นความลับที่ใช้เข้าถึงบัญชีได้ ต้องเก็บเอง ไม่มีอีเมลสำรอง หากลืมทั้งรหัสผ่านและรหัสกู้คืนยังไม่มี self-service recovery
- PWA ไม่แก้ไขรายการติดตามขณะออฟไลน์ ไม่แคช API หรือบัญชี แต่อุปกรณ์อาจแสดง snapshot ของหน้าต่างแอปใน app switcher ได้ตามระบบปฏิบัติการ
- ฟอนต์ยังโหลดจาก Google Fonts มี fallback เมื่อ offline ต้องพิจารณา self-host font หากต้องการลดการติดต่อบริการภายนอก
- ยังไม่มี stress test ระดับ production, security audit, accessibility audit เต็มรูปแบบ หรือการประเมินโดยผู้ใช้จริง 20 คน ผล 20 คนเป็น browser automation เท่านั้น
- Dockerfile/compose เตรียมแล้ว แต่เครื่องพัฒนานี้ไม่มี Docker จึงยังไม่ได้ build/run container

## การเปิดใช้งานต่อจากนี้

1. เปิดใช้ในเครื่องได้โดยไม่สมัครบริการเพิ่ม ข่าวต้องมีอินเทอร์เน็ตของเซิร์ฟเวอร์
2. ใช้บนมือถือผ่านอินเทอร์เน็ตต้องมีโฮสต์ Node/Docker, persistent disk และ HTTPS ก่อน ยังไม่มีการเช่าหรือผูกบริการใด
3. Groq เริ่มออนไลน์ได้ด้วย Free Plan แต่มีโควตาและส่งหัวข้อข่าวออกนอกเครื่อง ส่วน Ollama ฟรีโดยใช้ทรัพยากรเครื่อง การทำนายราคาและ Push ยังต้องออกแบบข้อมูล การวัดผล และระบบส่งเพิ่มเติม

คู่มือเปิดใช้และ backup อยู่ใน [OPERATIONS.md](OPERATIONS.md)
