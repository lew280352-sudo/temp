# สถานะและจุดบอดของ StockLens 0.6.1

ตรวจล่าสุดวันที่ 20 ตุลาคม 2026 แอปรันในเครื่องที่ `http://127.0.0.1:4173` และ health endpoint ตอบเวอร์ชัน 0.6.1

## สรุปจากรายการเดิม

| หัวข้อ | สถานะ | รายละเอียดปัจจุบัน |
| --- | --- | --- |
| เชื่อม AI | 🟡 ทำบางส่วน | เชื่อม Ollama/Qwen3 8B และมี Groq/Qwen 3.8 27B พร้อม fallback แล้ว แต่ `.env` ปัจจุบันยังไม่พบ `GROQ_API_KEY` จึงใช้ Ollama |
| สรุปข่าวภาษาไทย | ✅ ทำแล้ว | ผู้ใช้กดสรุปในหน้า AI Insights ได้ ผลแยกข้อเท็จจริง ปัจจัยบวก ความเสี่ยง สิ่งที่ไม่ทราบ และลิงก์ต้นฉบับ พร้อม cache |
| AI ทำนายขึ้น/ลง | ❌ ยังไม่มี | ไม่มีโมเดลพยากรณ์ราคา ไม่มีเปอร์เซ็นต์ความน่าจะเป็น และยังไม่มี backtest |
| ข่าวครอบคลุม | 🟡 ทำบางส่วน | ดึง RSS จริงและ cache จาก Apple, Microsoft, NVIDIA ทุก 15 นาที อีก 9 บริษัทมีค้นหา/ติดตามแต่ยังไม่มี feed |
| ข่าวอิสระ/คู่ค้า | ❌ ยังไม่มี | URL ที่ผู้ใช้เพิ่มเป็น preference/บุ๊กมาร์ก ยังไม่ crawl หรือสรุปอัตโนมัติ และยังไม่ตรวจข่าวข้ามแหล่ง |
| ค้นหาหุ้น | 🟡 ทำบางส่วน | ค้นหาได้ 12 บริษัทสหรัฐฯ พร้อม IR/SEC links ยังไม่รองรับทุก ticker |
| ข้อมูลพื้นฐานบริษัท | ❌ ยังไม่มี | ยังไม่มีงบการเงิน ผลประกอบการ ปันผล split, corporate actions หรือข้อมูลบริษัทอัตโนมัติ |
| ราคาหุ้น | 🟡 ทำบางส่วน | พบการตั้งค่า Finnhub key แล้ว ดึงราคา on-demand ของบริษัทที่ติดตาม พร้อม cache/เวลา/สถานะข้อมูลเก่า ไม่มีราคาจำลอง |
| กราฟและราคาย้อนหลัง | ❌ ยังไม่มี | ไม่มีกราฟ OHLC, history, FX, ค่าธรรมเนียม หรือภาษี |
| Push/อีเมล | ❌ ยังไม่มี | มีรายการข่าวและ preferences ภายในแอปเท่านั้น ไม่มี Web Push, อีเมล หรือ background delivery |
| PWA | 🟡 ทำบางส่วน | มี manifest, icons, install flow และหน้า offline แต่ยังไม่มี public HTTPS URL และยังไม่ทดสอบมือถือจริง |
| ใช้ผ่านอินเทอร์เน็ต | ❌ ยังไม่มี | ใช้ได้เฉพาะเครื่องที่รันเซิร์ฟเวอร์ ยังไม่มีโฮสต์ โดเมน HTTPS หรือ uptime monitoring |
| ระบบบัญชี | 🟡 ทำบางส่วน | Register/Login/Logout, password hash, HttpOnly session, recovery code ใช้ครั้งเดียว และเพิกถอน session เมื่อกู้คืนทำงานแล้ว |
| บัญชีสำหรับสาธารณะ | ❌ ยังไม่พร้อม | ยังไม่มียืนยันอีเมล, email reset, MFA, ลบบัญชี และหน้าจัดการอุปกรณ์ |
| Security/Accessibility | 🟡 ทำบางส่วน | มี origin/host checks, rate limiting, input limits, CSP, XSS escaping และ automated tests แต่ยังไม่มี external security audit หรือ accessibility audit เต็มรูปแบบ |

## สิ่งที่แอปทำได้แล้ว

- สมัคร เข้าใช้ ออกจากระบบ กู้บัญชีด้วย recovery code และแยกข้อมูลแต่ละบัญชี
- เลือกบริษัทและเว็บไซต์ที่อยากติดตาม โดยไม่เก็บจำนวนหุ้น ต้นทุน หรือมูลค่าพอร์ต
- ดึงหัวข้อข่าวจริง 3 แหล่ง พร้อมเวลา สถานะแหล่งข่าว cache และลิงก์ต้นฉบับ
- สรุปหัวข้อข่าวภาษาไทยด้วย Ollama หรือ Groq แบบ structured output; โหมด auto ใช้ Groq ก่อนและ fallback ไป Ollama
- ค้นหา 12 บริษัท เปิด Investor Relations/SEC และดูราคาล่าสุดผ่าน Finnhub
- ติดตั้งเป็น PWA บน localhost สำหรับทดสอบ มีหน้า offline ที่ไม่ cache ข้อมูลบัญชี
- SQLite, backup, export JSON, Docker configuration, privacy audit และชุดทดสอบผู้ใช้จำลอง 20 บัญชี

## ข้อจำกัดที่มีผลกับคุณตอนนี้

- AI อ่านเฉพาะหัวข้อ RSS และ metadata ไม่อ่านข้อความเต็ม งบการเงิน หรือราคาย้อนหลัง จึงอาจขาดบริบท
- ข่าวทั้ง 3 feed มาจากบริษัทเองและอาจมีมุมมองด้านเดียว ยังไม่ใช่การรวบรวมข่าวหลายสำนักที่น่าเชื่อถือครบถ้วน
- การอัปเดตทุก 15 นาทีคือเวลาตรวจ feed ไม่ได้หมายความว่าจะมีข่าวใหม่ทุก 15 นาที
- เมื่อคอมปิด เซิร์ฟเวอร์ การดึงข่าว และการแจ้งเตือนทั้งหมดหยุด
- หากลืมทั้งรหัสผ่านและ recovery code ยังไม่สามารถกู้บัญชีด้วยอีเมลได้
- ผลทดสอบผู้ใช้ 20 คนเป็น browser automation ไม่ใช่ผู้ใช้จริง และยังไม่มี production load test
- Dockerfile/compose มีแล้ว แต่ยังไม่ได้ build/run บนเครื่องนี้

## ลำดับงานที่ควรทำต่อ

1. บันทึก `GROQ_API_KEY` ให้ถูกชื่อและ restart เพื่อเปิด AI ออนไลน์ พร้อมคง Ollama เป็น fallback
2. เพิ่ม feed catalog จาก SEC และสื่อการเงินอิสระสำหรับ 12 บริษัท โดยใช้ allowlist ที่ปลอดภัย
3. เพิ่ม historical price + benchmark แล้วจึงสร้างโมเดลแนวโน้มและ backtest
4. หาโฮสต์ฟรี/ราคาต่ำที่มี persistent storage และ HTTPS ก่อนทำ Web Push
5. เพิ่ม email verification, account deletion, MFA และ security/accessibility audit ก่อนเปิดให้คนทั่วไป
