# คู่มือใช้งาน StockLens

## 1. เปิดแอป

เปิด Terminal ในโฟลเดอร์ที่มี `package.json` รัน `npm.cmd start` บน Windows หรือ `npm start` บน macOS/Linux แล้วเปิด http://127.0.0.1:4173 เปิด Terminal ค้างไว้ระหว่างใช้งาน กด Ctrl+C เพื่อหยุด

อย่าเปิดไฟล์ HTML โดยตรง ระบบสมาชิกต้องใช้เซิร์ฟเวอร์ ถ้ารันจาก clone ของ GitHub โฟลเดอร์ชื่อ `temp`; ถ้ารันจากงานเดิม โฟลเดอร์ชื่อ `stocklens` ต้องใช้ Node.js 24 ขึ้นไป

## 2. สมัครและเข้าสู่ระบบ

1. เลือก **สร้างบัญชี / Register**
2. ใส่ชื่ออย่างน้อย 2 ตัวอักษร อีเมล และรหัสผ่าน 10–128 ตัวอักษร
3. ยืนยันรหัสผ่านให้ตรงกัน แล้วกด **สร้างบัญชีของฉัน**
4. ระบบไปหน้า **เข้าสู่ระบบ / Login** ใส่รหัสผ่านแล้วเข้าสู่ระบบ

อีเมลเดียวสมัครซ้ำไม่ได้ บัญชีใหม่ไม่มีหุ้นเริ่มต้น ขณะนี้ยังไม่มีการยืนยันเจ้าของอีเมลหรือบริการกู้รหัสผ่าน จึงควรเก็บรหัสผ่านไว้ใน password manager

## 3. เพิ่มและจัดการพอร์ต

1. กด **เพิ่มหุ้นที่ติดตาม** หรือเปิด **พอร์ตของฉัน → เพิ่มหุ้น**
2. เลือกหุ้น ใส่จำนวนหุ้นเป็นจำนวนเต็ม และต้นทุนเฉลี่ยต่อหุ้น
3. กด **เพิ่มหุ้นในพอร์ต** รอข้อความยืนยันการบันทึก
4. เลือก **แก้ไข** เพื่อแทนที่จำนวนและต้นทุน หรือ **นำออก** เพื่อลบหลังยืนยัน

เมื่อเพิ่มหุ้นเดิม ระบบรวมจำนวนและคิดต้นทุนเฉลี่ยถ่วงน้ำหนัก ตัวอย่าง: 100 หุ้นที่ต้นทุน 30 บาท เพิ่มอีก 100 หุ้นที่ 34 บาท จะเป็น 200 หุ้น ต้นทุนเฉลี่ย 32 บาท

มูลค่าพอร์ต = จำนวนหุ้น × ราคาสาธิต; กำไร/ขาดทุน = มูลค่าพอร์ต − ต้นทุนรวม ไม่รวมค่าธรรมเนียม ภาษี ปันผล corporate actions หรือกำไรที่รับรู้จากการขาย ตัวเลขนี้ใช้ทดลองหน้าจอเท่านั้น

ถ้าข้อมูลเปลี่ยนจากอีกแท็บ ระบบปฏิเสธการเขียนทับและโหลดข้อมูลล่าสุดให้ ตรวจข้อมูลแล้วทำรายการใหม่ ถ้าบัญชีถูกสลับจากแท็บอื่น ระบบจะกลับหน้า Login

## 4. ค้นหาและอ่านข่าว

- เปิด **ค้นหาบริษัท** หรือกด `/` เมื่อไม่ได้พิมพ์ในช่องกรอก
- ค้นด้วยชื่อหุ้น ชื่อบริษัท หรือกลุ่มอุตสาหกรรม
- ชุดตัวอย่างมี PTT, ADVANC, CPALL, KBANK, AOT และ SCB
- เปิดบริษัทเพื่อเพิ่มเข้าพอร์ตหรือดู AI Insights
- ใน **ข่าวสาร & บทสรุป** เลือกทั้งหมด หุ้นในพอร์ต เว็บไซต์บริษัท คู่ค้า หรือสื่อการเงิน

**หัวข้อข่าวทั้งหมดเป็นสถานการณ์สมมติ** รายละเอียดข่าวไม่ได้อ้างว่ามีประกาศจริงจากบริษัท และไม่มีลิงก์ต้นฉบับของข่าวสมมติ

## 5. ใส่ URL เว็บไซต์

เปิด **แหล่งข้อมูล** ใน sidebar หรือไอคอนชั้นข้อมูลบนแถบบนของมือถือ

1. กรอกชื่อแหล่งข้อมูล เช่น “นักลงทุนสัมพันธ์บริษัท”
2. วาง URL เต็ม เช่น `https://investor.pttplc.com/en/ir-home`
3. เลือกประเภท: เว็บไซต์บริษัท / บริษัทคู่ค้า / แหล่งข่าวการเงิน
4. เลือกหุ้นที่เกี่ยวข้อง หรือ “ภาพรวม / ไม่ระบุหุ้น”
5. กด **บันทึกเว็บไซต์**

มีลิงก์เริ่มต้น:

- [SET ข่าวบริษัทจดทะเบียน](https://www.set.or.th/th/market/news-and-alert/news?newsType=company)
- [PTT นักลงทุนสัมพันธ์](https://investor.pttplc.com/en/ir-home)
- [AIS นักลงทุนสัมพันธ์](https://investor.ais.co.th/en/home)

กด URL เพื่อเปิดเว็บต้นทาง กดสวิตช์เพื่อเลือก/พักการติดตาม หรือกดลบแล้วยืนยัน URL ซ้ำไม่ถูกเพิ่ม จำกัด 50 เว็บไซต์ ไม่รับ javascript/file URL หรือ URL ที่ฝังรหัสผ่าน

**การบันทึก URL ยังไม่ดึงข่าว ไม่สรุปเนื้อหา และไม่ได้รับรองความน่าเชื่อถือของเว็บที่ผู้ใช้ใส่** สวิตช์เป็นการเก็บความต้องการสำหรับระบบดึงข่าวในอนาคต

## 6. AI Insights

เลือกหุ้นเพื่อดูหน้าตาแนวโน้มขึ้น/ทรงตัว/ลงในกรอบตัวอย่าง 5 วันทำการ กด **ดูเหตุผลและข้อจำกัด** เพื่ออ่านคำอธิบาย

เปอร์เซ็นต์ทั้งหมดเป็นค่าที่กำหนดในโค้ด ไม่ใช่ผลวิเคราะห์จริงหรือความแม่นยำที่ทดสอบแล้ว และ Custom GPT ของคุณยังไม่ได้เชื่อมต่อ ห้ามตีความว่าเป็นคำสั่งซื้อ/ขาย

## 7. ตั้งการแจ้งเตือน

เปิด **การแจ้งเตือน** เลือกบทสรุปรายวัน ข่าวสำคัญ หรือแนวโน้มเปลี่ยน ตั้งเวลาไทย และเลือกหุ้นในพอร์ตหรือทุกบริษัทในชุดสาธิต แล้วบันทึก

ระบบบันทึกการตั้งค่าได้จริง แต่ **ยังไม่ส่ง Push/อีเมล และไม่มีงานอัตโนมัติขณะปิดแอป** ตัวอย่างการแจ้งเตือนเป็น preview

## 8. ส่งออกข้อมูลและออกจากระบบ

- เดสก์ท็อป: กด **ดาวน์โหลดข้อมูลบัญชี** ใต้เมนู Logout เพื่อรับไฟล์ JSON
- ทุกอุปกรณ์: ขณะเข้าสู่ระบบ เปิด `/api/export` บน origin เดียวกับแอป เช่น http://127.0.0.1:4173/api/export
- ไฟล์มีข้อมูลบัญชี พอร์ต URL และการตั้งค่า ไม่รวม password hash หรือ session token เก็บไฟล์นี้เป็นข้อมูลส่วนตัว ยังไม่มีเมนู import JSON
- กด **ออกจากระบบ** ที่ sidebar หรือปุ่มอักษรชื่อบัญชีด้านขวาบนของมือถือ
- เซสชันหมดอายุหลังเข้าสู่ระบบ 12 ชั่วโมง Logout ยกเลิกเซสชันปัจจุบันทันที ไม่ได้ลบพอร์ตหรือบัญชี

## 9. แก้ปัญหาทั่วไป

| อาการ | วิธีแก้ |
| --- | --- |
| เปิด HTML แล้วมีข้อความให้เริ่มเซิร์ฟเวอร์ | รัน `npm.cmd start` แล้วเปิด URL localhost |
| `npm.ps1 cannot be loaded` | ใช้ `npm.cmd` บน Windows |
| `node:sqlite` ไม่พร้อมใช้งาน | ตรวจ `node --version` ให้เป็น 24 ขึ้นไป |
| พอร์ต 4173 ถูกใช้แล้ว | ใช้ `$env:PORT='4174'` แล้ว start ใหม่ เปิดพอร์ต 4174 |
| เข้าสู่ระบบไม่ได้ | ตรวจอีเมล/รหัสผ่านและว่าใช้เซิร์ฟเวอร์/ฐานข้อมูลเดียวกับตอนสมัคร |
| ถูกจำกัดการลองเข้าสู่ระบบ | รอ 15 นาที ตัวจำกัดพื้นฐานนับตาม IP รวมการสมัครและ Login |
| เซสชันหมดอายุ | Login ใหม่ ข้อมูลที่บันทึกสำเร็จยังอยู่ |
| ข้อมูลเปลี่ยนจากแท็บอื่น | ตรวจค่าที่โหลดล่าสุดแล้วแก้ไขใหม่ ไม่ต้องกดซ้ำเร็ว ๆ |
| ปิดเครื่องแล้วเข้าแอปไม่ได้ | เปิดเซิร์ฟเวอร์ใหม่ในโฟลเดอร์เดิม |
| ลืมรหัสผ่าน | เวอร์ชันนี้ยังไม่มีกู้รหัสผ่าน อย่าลบฐานข้อมูลเพื่อแก้เฉพาะบัญชี |
| GitHub Pages เปิดได้แต่ Login ไม่ทำงาน | ต้องใช้โฮสต์ที่รัน Node.js backend และมีพื้นที่เก็บฐานข้อมูลถาวร |
