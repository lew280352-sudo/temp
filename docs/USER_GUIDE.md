# คู่มือ StockLens 0.4 — หุ้นสหรัฐฯ / PWA

**อัปเดต 0.4.0:** เพิ่ม Local AI ตาม [LOCAL_AI.md](LOCAL_AI.md) และมีส่วนราคาหุ้น/มูลค่าประเมินในหน้า Overview/Portfolio ตั้งค่า Finnhub ตาม [FREE_SETUP.md](FREE_SETUP.md) ส่วนต้นทุนยังเป็นค่าที่กรอกเอง

## 1. เปิดแอป

ติดตั้ง Node.js 24+ เปิด Terminal ที่โฟลเดอร์โปรเจกต์ รัน `npm.cmd ci` ครั้งแรก แล้ว `npm.cmd start` จากนั้นเปิด http://127.0.0.1:4173 บนเครื่องเดียวกัน ปิด Terminal แล้วแอปจะหยุดทำงาน ข้อมูลยังอยู่ใน `.data/stocklens.sqlite`

หลังติดตั้งแพ็กเกจแล้วสามารถดับเบิลคลิก `start-stocklens.cmd` บน Windows ได้ ไม่ต้องเปิด `dist/index.html` โดยตรง เพราะระบบบัญชีต้องใช้เซิร์ฟเวอร์

## 2. สมัครสมาชิกและเก็บรหัสกู้คืน

1. กรอกชื่อ อีเมล รหัสผ่าน 10–128 ตัวอักษร และยืนยันรหัสผ่าน
2. กดสร้างบัญชี หน้าถัดไปแสดง **รหัสกู้คืนครั้งเดียว** คัดลอกเก็บในตัวจัดการรหัสผ่านหรือที่ปลอดภัยก่อน Login
3. เข้าสู่ระบบด้วยอีเมลและรหัสผ่านที่สมัคร ไม่ได้ส่งอีเมลยืนยันในเวอร์ชันนี้

ผู้ที่มีรหัสกู้คืนและอีเมลสามารถเปลี่ยนรหัสผ่านได้ อย่าแชร์รหัสนี้ หากรีเฟรชก่อนเก็บ ให้ Login แล้วไปการแจ้งเตือน → สร้างรหัสกู้คืนใหม่ โดยยืนยันรหัสผ่านปัจจุบัน รหัสเดิมจะถูกยกเลิกทันที บัญชีรุ่นเก่าต้องทำขั้นตอนนี้เพื่อเปิดใช้การกู้บัญชี

ลืมรหัสผ่าน: หน้า Login → ลืมรหัสผ่าน? ใช้รหัสกู้คืน → กรอกอีเมล รหัสกู้คืน และรหัสผ่านใหม่ → เก็บรหัสกู้คืนชุดใหม่ ระบบยกเลิกเซสชันทุกอุปกรณ์ หากไม่มีทั้งรหัสผ่านและรหัสกู้คืน จะยังไม่มีวิธีกู้ผ่านอีเมล

## 3. เพิ่มหุ้นในพอร์ต

กดเพิ่มหุ้น เลือกบริษัท กรอกจำนวน เช่น `0.125` และต้นทุนเฉลี่ยต่อหุ้นเป็น USD เพิ่มหุ้นเดิมอีกครั้งจะรวมจำนวนและคำนวณต้นทุนเฉลี่ยถ่วงน้ำหนัก กดแก้ไขเพื่อแทนที่ค่าปัจจุบัน หรือกดนำออกแล้วเลือกยืนยัน

รองรับ AAPL, MSFT, NVDA, AMZN, GOOGL, META, TSLA, BRK.B, JPM, V, WMT และ KO ยังเพิ่ม ticker นอกชุดนี้ไม่ได้ หุ้นไทยในบัญชีเดิมยังคงอยู่ แสดงต้นทุน THB แยกจาก USD ไม่แปลงค่าเงินอัตโนมัติ

**ยอดที่เห็นเป็นต้นทุน ไม่ใช่มูลค่าปัจจุบัน** ยังไม่มีบริการราคาตลาด จึงไม่มีการคำนวณกำไร/ขาดทุน ไม่รวมค่าธรรมเนียม ภาษี เงินปันผล หรือ corporate actions

## 4. ค้นหาบริษัท

ใช้เมนูค้นหาบริษัท ค้นชื่ออังกฤษ ชื่อไทย หรือ ticker เช่น `แอปเปิล`, `MSFT`, `NVIDIA` เปิดข้อมูลบริษัทเพื่อไปเว็บไซต์นักลงทุนสัมพันธ์หรือค้นเอกสาร SEC EDGAR และเพิ่มหุ้นเข้าพอร์ต

รายชื่อเป็น directory เริ่มต้น 12 บริษัท ไม่ใช่ระบบค้นหาทุกหลักทรัพย์ในสหรัฐฯ

## 5. ข่าวและเว็บไซต์ต้นทาง

แอปดึงหัวข้อ RSS จริงจาก:

- [Apple Newsroom](https://www.apple.com/newsroom/) — AAPL
- [Microsoft News](https://news.microsoft.com/) — MSFT
- [NVIDIA Newsroom](https://nvidianews.nvidia.com/) — NVDA

ตรวจฟีดเมื่อเริ่มเซิร์ฟเวอร์และทุก 15 นาที หากเปิดหน้าแอปค้างไว้จะโหลดรายการจากเซิร์ฟเวอร์ทุก 5 นาที กดรีเฟรชเพื่ออ่านรายการที่เซิร์ฟเวอร์มีล่าสุด ไม่ได้บังคับเว็บไซต์ต้นทางให้ออกข่าวใหม่

เลือกหุ้นในพอร์ตเพื่อกรองข่าว กดหัวข้อเพื่ออ่านต้นฉบับ มีเวลาเผยแพร่และสถานะของแต่ละแหล่งข่าว หากดึงใหม่ล้มเหลวจะยังอ่านข้อมูลเก่าพร้อมป้ายเตือนได้ เวลาเผยแพร่อาจเก่ากว่าเวลาดึงข้อมูล และไม่มีข่าวใหม่ในบางวัน

หน้าแหล่งข้อมูล: เปิด/ปิดฟีดเพื่อเปลี่ยนรายการข่าวของบัญชี บัญชีเดิมเพิ่มฟีดเริ่มต้นได้จากปุ่มเพิ่มฟีด หากเพิ่ม URL ของบริษัท คู่ค้า หรือเว็บการเงินอื่น จะเป็นบุ๊กมาร์ก ยังไม่ crawl หรือสรุปให้เอง รายการเพิ่มได้สูงสุด 50 เว็บไซต์

ข่าวทั้งหมดตอนนี้เป็นประกาศบริษัท ไม่ใช่การตรวจสอบข้ามแหล่งข่าวอิสระ และไม่คัดลอกบทความเต็ม เมื่อติดตั้ง Local AI แล้วสามารถสรุปได้จากหัวข้อเท่านั้น

## 6. AI และการแจ้งเตือน

ติดตั้ง Ollama และ Qwen3 8B ตาม [คู่มือ AI ฟรีในเครื่อง](LOCAL_AI.md) แล้วเปิดหน้า AI Insights เลือก AAPL, MSFT หรือ NVDA และกด **สรุปหัวข้อข่าวด้วย AI** ผลจะแยกข้อเท็จจริง ปัจจัยเชิงบวก ความเสี่ยง สิ่งที่ยังไม่ทราบ และลิงก์ต้นฉบับ โมเดลทำงานในเครื่องและผลเดิมถูก cache ใน SQLite

AI อ่านเฉพาะหัวข้อ RSS ไม่ใช่เนื้อหาบทความเต็ม และยังไม่ทำนายขึ้น/ลงหรือแสดงเปอร์เซ็นต์ราคา Custom GPT เดิมไม่ได้เชื่อมตรงกับแอป

หน้าแจ้งเตือนมีรายการข่าวตามพอร์ตหรือทุกฟีดที่เปิดไว้ ปิด “แสดงข่าวหุ้นที่ติดตาม” เพื่อซ่อนรายการนี้ การตั้งเวลารายวันและแนวโน้ม AI เก็บเป็นความต้องการเท่านั้น **ยังไม่มี Push/อีเมลเมื่อปิดแอป**

## 7. ติดตั้งเป็นแอป

บนคอม: เปิด localhost ด้วย Chrome/Edge แล้วกดติดตั้งเมื่อเบราว์เซอร์รองรับ หรือใช้เมนูติดตั้งของเบราว์เซอร์

บนมือถือ: ต้องมี URL HTTPS ของเซิร์ฟเวอร์ก่อน ขณะนี้ยังไม่ได้โฮสต์ออนไลน์ `localhost` บนมือถือหมายถึงมือถือเอง ไม่ใช่คอม และการเปิด IP ของคอมผ่าน HTTP ไม่ทำให้ติดตั้ง PWA ได้ครบ

- Android: เปิด URL HTTPS ด้วย Chrome แล้วใช้ปุ่มติดตั้งหรือเมนูติดตั้งแอป
- iPhone: เปิด URL HTTPS ใน Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม

[ข้อกำหนด PWA ตาม MDN](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)

เมื่อออฟไลน์ แอปจะแสดงหน้าขาดการเชื่อมต่อ ไม่บันทึกพอร์ต ไม่เข้าคิวแก้ไข และไม่เก็บข้อมูลบัญชีในแคช หากหน้าเดิมยังเปิดอยู่ อาจยังเห็นข้อมูลในหน่วยความจำจนกว่าจะออกจากหน้าหรือ Logout

## 8. ออกจากระบบและดาวน์โหลดข้อมูล

กดออกจากระบบในแถบด้านซ้าย หรือปุ่มอักษรย่อบัญชีมุมขวาบนมือถือ เซสชันอุปกรณ์นี้จะถูกยกเลิก หน้า Portfolio มีลิงก์ดาวน์โหลดข้อมูลบัญชี JSON ใช้ตรวจข้อมูลได้ แต่ยังนำกลับเข้าอัตโนมัติไม่ได้

## ปัญหาที่พบบ่อย

- เปิดไม่ได้: ตรวจ Terminal, Node.js 24+, `npm.cmd ci` และพอร์ต 4173 หากพอร์ตซ้ำตั้ง `$env:PORT='4174'` แล้วเริ่มใหม่
- ไม่มีข่าว: ดูสถานะแหล่งข่าว เปิดฟีดที่ต้องการ ตรวจอินเทอร์เน็ตของเซิร์ฟเวอร์ หรือเพิ่มหุ้น AAPL/MSFT/NVDA ให้ตรงฟีด
- บันทึกชนกับอีกแท็บ: ระบบโหลดข้อมูลล่าสุดให้ ตรวจค่าก่อนแก้ใหม่
- ลอง Login หลายครั้งแล้วถูกจำกัด: รอ 15 นาที ห้ามกดซ้ำรัว ๆ
- โฮสต์ถูกลบ/ดิสก์หาย: ต้องกู้จาก backup ฐานข้อมูล ไม่สามารถกู้ด้วยรหัสกู้บัญชีได้
