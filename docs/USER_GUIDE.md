# คู่มือ StockLens 0.8.1 — ข่าวบริษัทสหรัฐฯ / PWA

**อัปเดต 0.6.0:** รองรับ GroqCloud Free Plan สำหรับ AI ออนไลน์ และ Ollama เป็นตัวเลือกในเครื่อง ตาม [LOCAL_AI.md](LOCAL_AI.md)

## 1. เปิดแอป

ติดตั้ง Node.js 24+ เปิด Terminal ที่โฟลเดอร์โปรเจกต์ รัน `npm.cmd ci` ครั้งแรก แล้ว `npm.cmd start` จากนั้นเปิด http://127.0.0.1:4173 บนเครื่องเดียวกัน ปิด Terminal แล้วแอปจะหยุดทำงาน ข้อมูลยังอยู่ใน `.data/stocklens.sqlite`

หลังติดตั้งแพ็กเกจแล้วสามารถดับเบิลคลิก `start-stocklens.cmd` บน Windows ได้ ไม่ต้องเปิด `dist/index.html` โดยตรง เพราะระบบบัญชีต้องใช้เซิร์ฟเวอร์

## 2. สมัครสมาชิกและเก็บรหัสกู้คืน

1. กรอกชื่อ อีเมล รหัสผ่าน 10–128 ตัวอักษร และยืนยันรหัสผ่าน
2. กดสร้างบัญชี หน้าถัดไปแสดง **รหัสกู้คืนครั้งเดียว** คัดลอกเก็บในตัวจัดการรหัสผ่านหรือที่ปลอดภัยก่อน Login
3. เข้าสู่ระบบด้วยอีเมลและรหัสผ่านที่สมัคร หากผู้ดูแลตั้ง SMTP แล้ว ให้เปิดหน้า **การแจ้งเตือน → บัญชีและความปลอดภัย → ส่งลิงก์ยืนยันอีเมล** จากนั้นเปิดลิงก์ในอีเมลและกดยืนยันภายใน 1 ชั่วโมง ขณะนี้ยังไม่ได้ตั้ง SMTP จึงยังไม่มีอีเมลส่งจริง

ผู้ที่มีรหัสกู้คืนและอีเมลสามารถเปลี่ยนรหัสผ่านได้ อย่าแชร์รหัสนี้ หากรีเฟรชก่อนเก็บ ให้ Login แล้วไปการแจ้งเตือน → สร้างรหัสกู้คืนใหม่ โดยยืนยันรหัสผ่านปัจจุบัน รหัสเดิมจะถูกยกเลิกทันที บัญชีรุ่นเก่าต้องทำขั้นตอนนี้เพื่อเปิดใช้การกู้บัญชี

ลืมรหัสผ่าน: หน้า Login → ลืมรหัสผ่าน? ใช้รหัสกู้คืน → กรอกอีเมล รหัสกู้คืน และรหัสผ่านใหม่ → เก็บรหัสกู้คืนชุดใหม่ ระบบยกเลิกเซสชันทุกอุปกรณ์ หากไม่มีทั้งรหัสผ่านและรหัสกู้คืน จะยังไม่มีวิธีกู้ผ่านอีเมล

เปิด MFA: หน้า **การแจ้งเตือน → บัญชีและความปลอดภัย → เปิด MFA** ยืนยันรหัสผ่าน แล้วเพิ่มรหัสลับที่แสดงในแอป Authenticator ภายใน 10 นาที กรอกรหัส 6 หลักเพื่อเปิดใช้งาน หลังจากนั้น Login ต้องใช้ทั้งรหัสผ่านและรหัส Authenticator รหัสใช้ซ้ำในช่วงเวลาเดิมไม่ได้ การใช้รหัสกู้คืนบัญชีเพื่อเปลี่ยนรหัสผ่านจะปิด MFA และออกจากระบบทุกอุปกรณ์ หากต้องการลบบัญชี ใช้ปุ่ม **ลบบัญชี** ในหน้าเดียวกัน กรอกอีเมล รหัสผ่าน และรหัส MFA ถ้าเปิดอยู่ ข้อมูลในฐานข้อมูลใช้งานจะถูกลบ แต่สำเนาสำรองเก่าต้องจัดการแยกต่างหาก

## 3. เลือกบริษัทที่อยากติดตาม

ไปที่ **สิ่งที่ติดตาม** หรือ **ค้นหาบริษัท** แล้วกดติดตาม รองรับ AAPL, MSFT, NVDA, AMZN, GOOGL, META, TSLA, BRK.B, JPM, V, WMT และ KO การติดตามหมายถึงต้องการเห็นข่าวและราคาประกอบ ไม่ได้หมายความว่าคุณถือหุ้น

หากอัปเกรดจากรุ่นที่เคยเก็บพอร์ต ระบบจะย้ายเฉพาะ ticker สหรัฐฯ ที่รองรับมาเป็นรายการติดตาม แล้วลบจำนวนหุ้นและต้นทุนออกจาก state โดยอัตโนมัติ

## 4. ค้นหาบริษัท

ใช้เมนูค้นหาบริษัท ค้นชื่ออังกฤษ ชื่อไทย หรือ ticker เช่น `แอปเปิล`, `MSFT`, `NVIDIA` เปิดข้อมูลบริษัทเพื่อไปเว็บไซต์นักลงทุนสัมพันธ์หรือค้นเอกสาร SEC EDGAR แล้วเลือกติดตามข่าว

รายชื่อเป็น directory 36 บริษัทที่จดทะเบียนในสหรัฐฯ ไม่ใช่ระบบค้นหาทุกหลักทรัพย์ หุ้นใหม่ที่เพิ่ม ได้แก่ AVGO, ADBE, CSCO, IBM, UBER, ABNB, PYPL, PLTR, SBUX, NKE, HD และ CAT ไอคอนในหน้าค้นหา/ข่าว/รายการติดตามมาจากเว็บไซต์บริษัท 33 แห่ง; GOOGL, BRK.B และ PEP แสดงตัวย่อแทน

ช่องค้นหาช่องเดียวกันรับคำอิสระ เช่น `PTT`, `หุ้นญี่ปุ่น` หรือชื่อบริษัทที่ยังไม่อยู่ในแอป จากนั้นกด **ค้นใน Google News** หรือ **ค้นใน Bing News** เพื่อเปิดผลบนเว็บของผู้ให้บริการในแท็บใหม่ เมื่อกด คำค้นจะถูกส่งไปยังเว็บนั้น ผลค้นไม่ได้หมายถึงทุกข่าวบนอินเทอร์เน็ต และยังไม่เพิ่มหุ้นนั้นเข้ารายการติดตาม/AI/แจ้งเตือนของ StockLens

## 5. ข่าวและเว็บไซต์ต้นทาง

แอปดึงหัวข้อ RSS จริงจาก:

- [Apple Newsroom](https://www.apple.com/newsroom/) — AAPL
- [Microsoft News](https://news.microsoft.com/) — MSFT
- [NVIDIA Newsroom](https://nvidianews.nvidia.com/) — NVDA
- [Netflix Investor News](https://ir.netflix.net/) — NFLX

หากตั้ง Finnhub key แอปดึงข่าวการเงินสำหรับทั้ง 36 บริษัทจาก Finnhub อีกชุดหนึ่ง ข่าวติดชื่อสำนักจริง เช่น Yahoo, Seeking Alpha, Benzinga หรือ CNBC และมีลิงก์ต้นฉบับ ฟีดนี้ตรวจไม่เกินทุก 4 ชั่วโมง โดยไม่รับประกันว่าทุกบริษัทจะมีข่าวใหม่ในทุกวัน และอาจเจอโควตาผู้ให้บริการ เมื่อติดตามหุ้นตัวใหม่ แอปจะเพิ่มฟีด Finnhub ของหุ้นนั้นให้อัตโนมัติถ้ายังไม่มี

ตรวจฟีดเมื่อเริ่มเซิร์ฟเวอร์และทุก 15 นาที หากเปิดหน้าแอปค้างไว้จะโหลดรายการจากเซิร์ฟเวอร์ทุก 5 นาที กดรีเฟรชเพื่ออ่านรายการที่เซิร์ฟเวอร์มีล่าสุด ไม่ได้บังคับเว็บไซต์ต้นทางให้ออกข่าวใหม่

เลือก **สิ่งที่ติดตาม** เพื่อกรองข่าว กดหัวข้อเพื่ออ่านต้นฉบับ มีเวลาเผยแพร่และสถานะของแต่ละแหล่งข่าว หากดึงใหม่ล้มเหลวจะยังอ่านข้อมูลเก่าพร้อมป้ายเตือนได้ เวลาเผยแพร่อาจเก่ากว่าเวลาดึงข้อมูล และไม่มีข่าวใหม่ในบางวัน

หน้าแหล่งข้อมูล: เปิด/ปิดฟีดเพื่อเปลี่ยนรายการข่าวของบัญชี บัญชีเดิมเพิ่มฟีดเริ่มต้นได้จากปุ่มเพิ่มฟีด เพิ่มฟีด [Federal Reserve ข่าวประชาสัมพันธ์](https://www.federalreserve.gov/feeds/press_all.xml) หรือ [นโยบายการเงิน](https://www.federalreserve.gov/feeds/press_monetary.xml) ด้วยปุ่มหรือ URL ตรงตามนี้แล้วแอปจะดึงหัวข้อ RSS จริง ฟีดเหล่านี้เป็นข่าวภาพรวม ไม่ผูกกับหุ้นตัวใดและไม่เข้าโหมด AI สรุปหุ้นรายบริษัท URL อื่นที่ยังไม่ตรวจสอบเป็นบุ๊กมาร์ก ไม่ถูกเซิร์ฟเวอร์ดึงข้อมูล รายการรวมเพิ่มได้สูงสุด 100 เว็บไซต์

ข่าวจาก RSS บริษัทเป็นประกาศบริษัท ฟีด Federal Reserve เป็นข่าวหน่วยงานทางการ ส่วนข่าวผ่าน Finnhub เป็นสื่อการเงินที่แสดงชื่อผู้เผยแพร่ ยังไม่ได้ตรวจข้อเท็จจริงข้ามสำนักหรือยืนยันข่าวคู่ค้า และไม่คัดลอกบทความเต็ม เมื่อเปิดใช้ Groq หรือ Ollama แล้วสามารถสรุปได้จากหัวข้อข่าวที่ผูกกับบริษัทเท่านั้น

## 6. AI และการแจ้งเตือน

ตั้ง Groq API key ฟรีหรือใช้ Ollama ตาม [คู่มือ AI](LOCAL_AI.md) แล้วเปิดหน้า AI Insights เลือกบริษัทที่มีข่าวและกด **สรุปหัวข้อข่าวด้วย AI** ผลจะแยกข้อเท็จจริง ปัจจัยเชิงบวก ความเสี่ยง สิ่งที่ยังไม่ทราบ และลิงก์ต้นฉบับ ผลเดิมถูก cache ใน SQLite

AI อ่านเฉพาะหัวข้อข่าว ไม่ใช่เนื้อหาบทความเต็ม หากเพิ่ม Alpha Vantage key ฟรีใน `.env` หน้าเดียวกันจะแสดงกราฟราคาปิดรายสัปดาห์ที่จบแล้วสูงสุด 104 สัปดาห์ และทดสอบกฎแนวโน้ม 4 สัปดาห์เพื่อดูผลสัปดาห์ถัดไป โดยใช้ราคาปิดแบบปรับ split/ปันผลและทดสอบย้อนหลัง 5 ปี ถ้า backtest ไม่ผ่านจะแสดงเหตุผลและไม่ให้สัญญาณ แต่ยังแสดงแนวโน้ม 4 สัปดาห์ที่เกิดขึ้นแล้วโดยระบุว่าไม่ใช่คำทำนาย ไม่มีเปอร์เซ็นต์ความน่าจะเป็นหรือผลทำนายจาก Groq Custom GPT เดิมไม่ได้เชื่อมตรงกับแอป

หน้าแจ้งเตือนมีรายการข่าวตามบริษัทที่ติดตามหรือทุกฟีดที่เปิดไว้ ปิด “แสดงและแจ้ง Push ข่าวบริษัทที่เลือก” เพื่อปิดทั้งรายการและการส่ง Push กด **เปิด Push บนอุปกรณ์นี้** แล้วอนุญาตเบราว์เซอร์ กด **ส่งทดสอบ** เพื่อตรวจการรับจริง Web Push อาจแจ้งข่าวใหม่เมื่อปิดหน้าแอปแต่เซิร์ฟเวอร์ยังทำงานและอุปกรณ์ออนไลน์ การตั้งเวลารายวันและแนวโน้ม AI เก็บเป็นความต้องการเท่านั้น ยังไม่มีอีเมลแจ้งข่าวหรือสรุปรายวัน

## 7. ติดตั้งเป็นแอป

บนคอม: เปิด localhost ด้วย Chrome/Edge แล้วกดติดตั้งเมื่อเบราว์เซอร์รองรับ หรือใช้เมนูติดตั้งของเบราว์เซอร์

บนมือถือ: ต้องมี URL HTTPS ของเซิร์ฟเวอร์ก่อน ขณะนี้ยังไม่ได้โฮสต์ออนไลน์ `localhost` บนมือถือหมายถึงมือถือเอง ไม่ใช่คอม และการเปิด IP ของคอมผ่าน HTTP ไม่ทำให้ติดตั้ง PWA ได้ครบ

- Android: เปิด URL HTTPS ด้วย Chrome แล้วใช้ปุ่มติดตั้งหรือเมนูติดตั้งแอป
- iPhone: เปิด URL HTTPS ใน Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม

[ข้อกำหนด PWA ตาม MDN](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)

เมื่อออฟไลน์ แอปจะแสดงหน้าขาดการเชื่อมต่อ ไม่บันทึกการเปลี่ยนแปลง ไม่เข้าคิวแก้ไข และไม่เก็บข้อมูลบัญชีในแคช หากหน้าเดิมยังเปิดอยู่ อาจยังเห็นข้อมูลในหน่วยความจำจนกว่าจะออกจากหน้าหรือ Logout

## 8. ออกจากระบบและดาวน์โหลดข้อมูล

กดออกจากระบบในแถบด้านซ้าย หรือปุ่มอักษรย่อบัญชีมุมขวาบนมือถือ เซสชันอุปกรณ์นี้จะถูกยกเลิก หน้า **สิ่งที่ติดตาม** มีลิงก์ดาวน์โหลดข้อมูลบัญชี JSON ใช้ตรวจข้อมูลได้ แต่ยังนำกลับเข้าอัตโนมัติไม่ได้

## ปัญหาที่พบบ่อย

- เปิดไม่ได้: ตรวจ Terminal, Node.js 24+, `npm.cmd ci` และพอร์ต 4173 หากพอร์ตซ้ำตั้ง `$env:PORT='4174'` แล้วเริ่มใหม่
- ไม่มีข่าว: ดูสถานะแหล่งข่าว เปิดฟีดที่ต้องการ ตรวจอินเทอร์เน็ตของเซิร์ฟเวอร์ และตรวจว่ามี Finnhub key สำหรับข่าวสื่อการเงิน
- บันทึกชนกับอีกแท็บ: ระบบโหลดข้อมูลล่าสุดให้ ตรวจค่าก่อนแก้ใหม่
- ลอง Login หลายครั้งแล้วถูกจำกัด: รอ 15 นาที ห้ามกดซ้ำรัว ๆ
- โฮสต์ถูกลบ/ดิสก์หาย: ต้องกู้จาก backup ฐานข้อมูล ไม่สามารถกู้ด้วยรหัสกู้บัญชีได้
