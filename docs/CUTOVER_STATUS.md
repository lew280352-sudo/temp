# สถานะการย้ายข้อมูลและเปิดใช้งาน — 6 พฤศจิกายน 2026

## คำสั่งล่าสุด

เจ้าของยืนยันวันที่ 6 พฤศจิกายน 2026 ว่าไม่จำเป็นต้องใช้ฐานข้อมูลเดิม ให้เริ่มฐานใหม่ได้ จึงยกเลิกการรอผลค้นไฟล์จาก Windows เครื่องมือค้นหาด้านล่างคงไว้เป็นทางเลือก ไม่ใช่เงื่อนไขเปิดโฮสต์

ขั้นตอนที่ต้องทำตอนนี้: เพิ่ม Render และลงชื่อเข้าใช้ จากนั้นสร้าง Turso libSQL แผน Free และตั้ง URL/token ใน secret/environment ก่อน deploy ตาม [คู่มือเริ่มฐานใหม่](FREE_CLOUD.md#2-เริ่มฐานใหม่ตามคำสั่งล่าสุด)

พรีวิว Codespace เป็นบริการชั่วคราวและเป็นส่วนตัว ไม่ใช่หลักฐานว่าฐานข้อมูลถูกย้ายหรือโฮสต์ถาวรพร้อมแล้ว

## ค้นฐานบน Windows เดิม

ต้องใช้ Node.js 24+ บนคอมที่เคยเปิดแอปเดิม สคริปต์ค้นหาเป็นไฟล์เดี่ยว ใช้โมดูลของ Node เท่านั้น ไม่ต้องติดตั้งแพ็กเกจ และเปิด SQLite แบบอ่านอย่างเดียว แสดงเพียง path กับจำนวนแถว ไม่แสดงอีเมล รหัสผ่าน รายการติดตาม หรือคีย์

หากมีชุดโค้ด branch นี้อยู่แล้ว ดับเบิลคลิก `find-stocklens-data.cmd` หรือรัน:

```powershell
node scripts/find-legacy-data.mjs
```

หากมีเฉพาะแอปเวอร์ชันเก่า ดาวน์โหลดสคริปต์ไฟล์เดียวจาก branch ที่เตรียมไว้แล้วรันใน PowerShell:

```powershell
Invoke-WebRequest -Uri 'https://raw.githubusercontent.com/lew280352-sudo/temp/feat/stocklens-ui-and-online/scripts/find-legacy-data.mjs' -OutFile "$env:TEMP\stocklens-find-legacy.mjs"
node "$env:TEMP\stocklens-find-legacy.mjs"
```

ค้นใน home directory และโฟลเดอร์ที่รันโดยปริยาย หากแอปอยู่ไดรฟ์อื่น ให้ระบุโฟลเดอร์จริง เช่น `node scripts/find-legacy-data.mjs D:\Projects` ข้าม symlink, node_modules, .git และไดเรกทอรีระบบบางส่วน จำกัดความลึก 10 ระดับ ผลว่าไม่พบจึงไม่ได้ยืนยันว่าไม่มีไฟล์นอกพื้นที่ค้น

รายงาน path และ counts ของไฟล์ที่มี users มากกว่า 0 เพื่อระบุต้นทางก่อน ไม่ย้ายอัตโนมัติจากชื่อไฟล์เพียงอย่างเดียว หลังยืนยันแล้วหยุดการเขียนแอปเดิมและทำ final backup ตาม [FREE_CLOUD.md](FREE_CLOUD.md) ต้องรักษาคีย์ MFA/VAPID เดิมหากใช้งานอยู่

## ตรวจบริการหลังตั้งค่า

[ผล probe ที่บันทึกไว้](service-check-2026-11-06.json) ระบุสถานะบริการที่ยังไม่ได้ตั้งค่าแยกจาก RSS ที่ดึงสำเร็จ

```sh
npm run check:services
```

คำสั่งดึง RSS จริง ตรวจการเชื่อมฐานข้อมูล/AI/SMTP เฉพาะที่ตั้งค่าไว้ แสดงผลโดยไม่พิมพ์คีย์ และไม่ส่งอีเมลหรือ Push ไปหาผู้รับที่ไม่ได้ระบุ Exit 2 หมายถึงยังไม่พร้อมครบทุกบริการ ไม่ใช่การยืนยันระบบปลายทาง ช่อง `ready` คงเป็น false เพราะ CLI นี้ไม่สามารถยืนยันการส่งถึงกล่องอีเมลหรือมือถือได้

บน Render Free พอร์ต SMTP ถูกบล็อกและ blueprint ปิด email-login OTP ต้องจัดผู้ให้บริการอีเมลผ่าน HTTPS เพิ่มจึงจะเปิดความสามารถอีเมลบนโฮสต์นั้นได้ อ่าน [ข้อจำกัด Render](https://render.com/docs/free) ขั้นตอนเปิด Push จริงคือเข้าหน้าแจ้งเตือนจาก HTTPS บนอุปกรณ์ที่รองรับ อนุญาตการแจ้งเตือน แล้วกดส่งทดสอบและตรวจบนอุปกรณ์นั้น เซิร์ฟเวอร์ฟรีที่พักอยู่จะไม่ดึงข่าวหรือส่ง Push ระหว่างพัก
