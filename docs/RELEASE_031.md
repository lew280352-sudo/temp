# รุ่น 0.3.1 — ราคาเมื่อเปิดแอป

เพิ่มตัวเชื่อม Finnhub ฝั่งเซิร์ฟเวอร์ ไม่ต้องเช่าโฮสต์ ใช้ `.env` ใส่ key ของบัญชีส่วนตัวก่อนดึงราคาจริง คู่มือ: [FREE_SETUP.md](FREE_SETUP.md)

- ดึงเฉพาะหุ้นในพอร์ตเมื่อ Login/เข้าแอป เปิดพอร์ต เปลี่ยนหุ้น หรือกดอัปเดต ไม่มี price scheduler
- เก็บผลและเวลาลองดึงใน SQLite; ใช้ cooldown 60 วินาทีทั้งสำเร็จและล้มเหลว รวมคำขอหุ้นเดียวกันจากหลายบัญชี
- เก็บราคาดีล่าสุดเมื่อ provider ล่ม/เกินโควตา พร้อมแสดงข้อมูลเก่า ไม่แทนค่าด้วยศูนย์
- แสดงเวลาของราคาแยกจากเวลาดึง และไม่รวมยอดพอร์ตถ้าราคา USD ไม่ครบ ไม่รวมต้นทุน THB กับ USD
- API ต้องมี session ตรวจสิทธิ์ซ้ำหลังรอ provider, key ไม่ส่งออกหน้าเว็บ ไม่ตาม redirect และจำกัดขนาด/เวลารอข้อมูล

## ผลทดสอบ 18 ตุลาคม 2026

API/unit/persistence 13 tests ผ่าน; desktop/mobile UI และ PWA ผ่าน รวมราคา fixture, fractional-share valuation, ราคาไม่ครบ, source filtering, recovery และ offline privacy

ผู้ใช้สังเคราะห์ 20/20 ผ่าน (10 desktop + 10 mobile viewport) บน Windows/Edge ในเครื่องเดียวกัน 536 API requests ไม่มี 429/5xx ใช้เวลา 42.567 วินาที มีการรัน PWA suite พร้อมกัน จึงไม่ใช้ตัวเลขรอบนี้เปรียบเทียบสมรรถนะกับรอบก่อน

**ยังไม่มี API key ของผู้ใช้ จึงยังไม่ได้ยืนยันราคาจริงหรือสิทธิ์ตลาดของบัญชี Finnhub** ตัวเลขใน browser tests เป็น fixtures ที่ไม่ถูกนำไปใช้ในแอปจริง ยังไม่ได้ทำ AI, Push หรือเช่าโฮสต์เพิ่มเติม
