# ลองใช้ StockLens 0.9.1 แบบผู้ใช้ — 21 ตุลาคม 2026

ตรวจเส้นทางสมัคร → เข้าสู่ระบบ → เลือกหุ้นและแหล่งข่าว → อ่านข่าว/ราคา/กราฟ → ค้นข่าวย้อนหลังและสรุป AI → ตั้งการแจ้งเตือน → ออกจากระบบ รวมการทดสอบหน้าจอมือถือและบัญชีจำลอง 20 ราย เครื่องทดสอบใช้ฐานข้อมูลแยกจากบัญชีจริง และตรวจ API ภายนอกด้วยคีย์ที่ตั้งไว้ในเครื่องโดยไม่บันทึกคีย์ลงรายงาน การจำลองนี้ตรวจการทำงานได้ แต่ยังไม่แทนการให้ผู้ใช้จริงลองใช้หรือการตรวจความปลอดภัยภายนอก

ผลตรวจระบบ: ชุดทดสอบ unit/API ผ่าน 39 รายการ; UI, research UI, security UI และ PWA ใช้เบราว์เซอร์ทดสอบ; การจำลอง 20 บัญชีผ่านทุกขั้นตอน รวมสมัคร/Login/Logout/กู้คืน/MFA/ลบบัญชี รายการติดตาม แหล่งข่าว และ AI การตรวจบริการจริงพบ Finnhub ส่งราคาหุ้น AAPL กลับมา, ฟีดข่าว Apple และข่าวการเงิน AAPL ส่งข่าวจริง, Alpha Vantage มีราคาย้อนหลัง 104 สัปดาห์, Groq ส่งสรุปข่าวภาษาไทยกลับมา ขณะตรวจ ราคาล่าสุดอาจเก่าตามเวลาตลาดและสิทธิ์ผู้ให้บริการ

จุดที่ยังต้องทำ เรียงตามผลกระทบต่อผู้ใช้:

1. **ใช้บนมือถือจากนอกบ้านและ Push จริง:** ยังไม่มี public HTTPS และเซิร์ฟเวอร์ที่เปิดตลอด จึงยังไม่ได้ทดสอบการส่งถึงโทรศัพท์เมื่อปิดแอป แม้ VAPID และหน้าตั้งค่าทำงานแล้ว ควรนำขึ้นโฮสต์ HTTPS ที่มีดิสก์ถาวร แล้วทดสอบ Push กับ Android/iPhone จริงก่อนอ้างว่าแจ้งเตือนได้เสมอ
2. **อีเมลยืนยันบัญชี:** ไม่มี SMTP ที่ใช้งานจริง จึงยังไม่ได้ทดสอบการรับอีเมลจริง ควรเชื่อมผู้ให้บริการอีเมล ตรวจ SPF/DKIM และทดลองสมัครด้วยอีเมลทดสอบก่อนเปิดให้คนทั่วไป
3. **การติดตามยังจำกัด 36 หุ้นสหรัฐฯ:** ค้นข่าวย้อนหลังของบริษัทอื่นผ่าน Finnhub ได้ แต่เพิ่มเข้ารายการติดตาม/แจ้งเตือนไม่ได้ ควรเพิ่มขั้นตอนตรวจ ticker และตลาดจาก API ก่อนอนุญาตติดตาม โดยคุมโควตาข่าวและข้อมูลราคา
4. **ความครบถ้วนของข่าวและ AI:** สรุปจากหัวข้อข่าว/metadata สูงสุด 10 รายการ ไม่ได้อ่านบทความเต็ม และฟีด/โควตาอาจขาดข่าว ควรเพิ่มแหล่งที่มีสิทธิ์ใช้ ตรวจการซ้ำและความเกี่ยวข้อง พร้อมแสดงจำนวนข่าวที่ถูกตัดออกอย่างชัดเจน
5. **สัญญาณขึ้น/ลง:** ผล AAPL ที่ตรวจได้มีความถูกต้องประมาณ 53.8% ต่ำกว่า baseline 55% และเกณฑ์ขั้นต่ำ 60% แอปจึงไม่แสดงสัญญาณ นี่เป็นพฤติกรรมที่ถูกต้อง ควรปรับวิธีวิจัยและทำ backtest แบบเดินเวลา/กันข้อมูลรั่วก่อนเปิดใช้ ไม่ควรลดเกณฑ์เพื่อบังคับให้ขึ้นคำทำนาย
6. **ทดสอบกับคนจริงและตรวจภายนอก:** การจำลอง 20 บัญชีไม่บอกว่าข้อความเข้าใจง่ายหรือไม่ ควรให้ผู้ใช้ใหม่ 5–8 คนลองทำงานหลักโดยไม่ช่วย แล้วบันทึกเวลาสำเร็จ/จุดพลาด รวมตรวจ accessibility และให้ผู้ตรวจอิสระทบทวนความปลอดภัยก่อนเผยแพร่สาธารณะ

คำแนะนำลำดับถัดไป: ให้ผู้ใช้จริงลอง 5–8 คนพร้อมบันทึกจุดงง, จัดโฮสต์ HTTPS เพื่อพิสูจน์ Push และการใช้มือถือภายนอก, เชื่อมอีเมล, แล้วขยายหุ้น/แหล่งข่าวโดยไม่ฝืนโควตาฟรี ผล AI และแนวโน้มราคาต้องแสดงแหล่ง เวลา และข้อจำกัดต่อไป
