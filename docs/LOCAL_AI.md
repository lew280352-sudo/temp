# ใช้ AI ฟรีใน StockLens

StockLens 0.4 ใช้ **Ollama + Qwen3 8B** บนเครื่อง ไม่ต้องสมัครบริการ AI และไม่มีค่า API ข้อความหัวข้อข่าวถูกส่งระหว่าง StockLens กับ `127.0.0.1` เท่านั้น โมเดลประมาณ 5.2 GB เหมาะกับเครื่องนี้ที่มี RTX 3070 8 GB แต่การสร้างคำตอบครั้งแรกอาจใช้เวลาสักครู่

## ติดตั้งบน Windows

1. ดาวน์โหลด Ollama จาก [หน้า Download ทางการ](https://ollama.com/download/windows) แล้วติดตั้ง
2. เปิด PowerShell ใหม่ แล้วดาวน์โหลดโมเดลครั้งเดียว:

   ```powershell
   ollama pull qwen3:8b
   ```

3. ตรวจว่าโมเดลพร้อมด้วย `ollama list`
4. เปิด StockLens ใหม่ด้วย `npm.cmd start` จากนั้น Login → **AI Insights** → เลือก AAPL, MSFT หรือ NVDA → **สรุปหัวข้อข่าวด้วย AI**

ค่าปกติอยู่ใน `.env.example` หากต้องการปิด AI ใส่ `AI_ENABLED=false` ใน `.env` แล้ว restart StockLens ห้ามเปลี่ยน `OLLAMA_URL` เป็นเครื่องภายนอก ระบบอนุญาตเฉพาะ localhost เพื่อไม่ส่งข้อมูลออกจากเครื่อง

## ถ้า AI ยังไม่พร้อม

- `ollama` ไม่พบ: ปิดแล้วเปิด PowerShell ใหม่ หรือเปิด Ollama จาก Start Menu
- ขึ้น “ยังไม่พบโมเดล”: รัน `ollama pull qwen3:8b` ให้เสร็จ และตรวจพื้นที่ว่างอย่างน้อย 6 GB
- ไม่มีหัวข้อข่าว: เลือก AAPL, MSFT หรือ NVDA และเปิดฟีดบริษัทในหน้าแหล่งข้อมูล
- ตอบช้า: คำตอบแรกต้องโหลดโมเดลเข้า GPU; ผลเดิมจะถูกเก็บใน SQLite และเปิดครั้งต่อไปเร็วขึ้น

## ขอบเขตความสามารถ

AI สรุปจาก **หัวข้อข่าวและ metadata ของ RSS** ไม่ได้อ่านเนื้อหาบทความเต็ม จึงแสดงข้อเท็จจริง การตีความ ความเสี่ยง และข้อมูลที่ยังขาด พร้อมลิงก์ต้นฉบับ ไม่มีการทำนายว่าราคาจะขึ้นหรือลง เพราะยังไม่มีชุดข้อมูลราคา การทดสอบย้อนหลัง และเกณฑ์วัดความแม่นยำที่เพียงพอ

Custom GPT ที่สร้างใน ChatGPT ใช้ตรงกับ backend นี้ไม่ได้โดยไม่มี API และระบบยืนยันตัวตนแยก การใช้ Ollama ทำให้เริ่มได้ฟรีและข้อมูลอยู่ในเครื่อง
