# ใช้ StockLens บนเครื่องโดยไม่เช่าโฮสต์ + ตั้งค่าราคาหุ้น

## สรุปขอบเขต

ใช้คอมของคุณเป็นเซิร์ฟเวอร์ ไม่ต้องสมัคร Render ไม่ต้องเช่าโฮสต์หรือซื้อโดเมน ระบบสมาชิก พอร์ต และ RSS ใช้งานได้เหมือนเดิม ส่วนราคาหุ้นเพิ่มตัวเชื่อม Finnhub แล้ว แต่ **ยังไม่ได้เปิดดึงราคาจริง เพราะยังไม่มี API key**

ราคาดึงเฉพาะหุ้นสหรัฐฯ ที่มีในพอร์ตตอน Login/เปิดแอป เปิดหน้า Portfolio เพิ่มหรือแก้หุ้น และกด “อัปเดตราคา” ไม่มีงานตั้งเวลาดึงราคาเมื่อปิดแอป ใช้ข้อมูลเดิมอย่างน้อย 60 วินาทีต่อหุ้น ลดการใช้โควตาเมื่อหลายแท็บหรือหลายบัญชีขอหุ้นเดียวกัน RSS ข่าวยังทำงานทุก 15 นาทีขณะเซิร์ฟเวอร์เปิดตามเดิม

## 1. สมัครบัญชีข้อมูลราคา

1. เปิด [Finnhub](https://finnhub.io/) แล้วเลือกสมัครบัญชี / Sign up
2. ใช้อีเมลของคุณ ตั้งรหัสผ่านและยืนยันอีเมลตามขั้นตอนที่เว็บแสดง
3. เลือกแผน **Free** ตรวจเงื่อนไขและสิทธิ์ใช้งานใน [หน้าราคา](https://finnhub.io/pricing) ก่อนเริ่ม หากหน้าใดให้ยืนยันแพ็กเกจเสียเงินหรือจ่ายเงิน ให้หยุด ไม่จำเป็นต้องซื้อเพื่อทดสอบระบบที่เตรียมไว้
4. เข้าหน้า Dashboard ของบัญชีแล้วคัดลอก API key เก็บไว้บนเครื่อง ไม่ส่งในแชตหรือ GitHub

ชื่อเมนู โควตา และสิทธิ์ข้อมูลอาจเปลี่ยนตามบริการ อย่าสรุปว่าได้ราคาทุกตลาดแบบ real-time หรือมีสิทธิ์เผยแพร่ให้ผู้อื่นเพียงเพราะสร้าง key ได้ ใช้เริ่มต้นส่วนตัวและตรวจสิทธิ์แพ็กเกจก่อนเผยแพร่

## 2. ใส่ key บนคอม

ที่โฟลเดอร์ `stocklens` สร้างไฟล์ชื่อ `.env` (ไม่มี `.txt` ต่อท้าย) ถ้ายังไม่มีไฟล์นี้ ให้คัดลอก `.env.example` มาเป็น `.env` หากมีอยู่แล้วให้แก้ไฟล์เดิม ไม่เขียนทับค่าอื่น

เพิ่มหรือแก้บรรทัดนี้ให้มีเพียงครั้งเดียว:

```dotenv
FINNHUB_API_KEY=ใส่_key_จากบัญชีของคุณตรงนี้
```

อย่าใส่ key ใน `dist/`, JavaScript หน้าเว็บ หรือเอกสาร Git ไฟล์ `.env` ถูก ignore แล้ว แต่ยังต้องรักษาความปลอดภัยของเครื่อง หาก key หลุดให้ยกเลิกและสร้างใหม่ที่ผู้ให้บริการ

## 3. เริ่มเซิร์ฟเวอร์ใหม่

หยุดเซิร์ฟเวอร์เดิมก่อน เพื่อให้โหลด `.env` ใหม่ ถ้าเปิดใน Terminal ให้กด Ctrl+C จากนั้นเปิด Terminal ที่โฟลเดอร์ `stocklens` แล้วรัน:

```powershell
npm.cmd start
```

เปิด http://127.0.0.1:4173 → Login → เพิ่มหุ้น เช่น AAPL → ไปหน้า Portfolio → ดูส่วน “ราคาหุ้นในพอร์ต · USD” หากมีเซิร์ฟเวอร์ที่เปิดซ่อนไว้ อย่าเปิดซ้ำแล้วใช้พอร์ตเดิมโดยไม่หยุดตัวเดิมก่อน ติดต่อให้ช่วยหยุดเฉพาะ process ของ StockLens ได้

ปุ่ม “อัปเดตราคา” จะอ่านราคาครั้งล่าสุดจากเซิร์ฟเวอร์ หากยังอยู่ใน 60 วินาทีจะใช้ cache เพื่อไม่ยิง API ซ้ำ ภายในแอปไม่มีการสมัครหรืออัปเกรดแพ็กเกจอัตโนมัติ

## 4. อ่านผลให้ถูกต้อง

- แสดงทั้ง **เวลาราคาจากผู้ให้บริการ** และ **เวลาที่แอปดึงข้อมูล** ซึ่งอาจไม่ใช่เวลาเดียวกัน
- ราคาที่มีอายุมากกว่า 15 นาทีจะมีข้อความบอก อาจเกิดจากตลาดปิด ข้อมูลล่าช้า หรือสิทธิ์แพ็กเกจ ไม่รับประกันราคาสด
- ถ้าเน็ตหลุดหรือโควตาเต็ม จะเก็บราคาที่ดึงสำเร็จครั้งก่อนและแสดงว่าเก่า ไม่แทนด้วยศูนย์หรือค่าจำลอง
- ถ้ายังมีราคาหุ้นสหรัฐฯ ไม่ครบ จะไม่แสดงยอดรวมพอร์ตที่ดูเหมือนครบ แสดงเฉพาะมูลค่ารายหุ้นที่มีราคา
- กำไร/ขาดทุนเป็นค่าประเมินจากราคาที่ได้รับกับต้นทุนที่คุณกรอก ไม่รวมค่าธรรมเนียม ภาษี เงินปันผล หรือ FX หุ้นไทยเดิมไม่ถูกนำมารวมใน USD
- ไม่มี API key: ระบบบอกขั้นตอนตั้งค่าและไม่ส่งคำขอไป Finnhub

## ยังไม่เปลี่ยนในรอบนี้

ยังไม่มีโฮสต์ HTTPS ออนไลน์, Push เมื่อปิดแอป หรือ AI/Custom GPT ที่ทำงานจริง และยังไม่ได้ติดตั้งโมเดล AI ลงคอม ราคาหุ้นที่เพิ่มนี้ไม่ใช่การทำนายทิศทาง

## สำหรับผู้ดูแล

`GET /api/quotes` ต้อง Login และคืนเฉพาะหุ้นในพอร์ตปัจจุบัน ไม่รับ ticker จาก query ภายนอก Key ใช้เฉพาะ server header `X-Finnhub-Token` ฐานข้อมูล `stock_quotes` เก็บเฉพาะราคา เวลา และข้อผิดพลาด ไม่มี key และรวมอยู่ใน backup ของ SQLite

ตัวเชื่อมจำกัดปลายทางคงที่ ไม่ตาม redirect, timeout 8 วินาที, response 64 KiB ตรวจราคาเป็นบวกและ timestamp ก่อนบันทึก แชร์ cache ระหว่างบัญชีสำหรับราคาสาธารณะ และตรวจเซสชันซ้ำเมื่อ API ตอบกลับ ไม่มี timer สำหรับราคา

การทดสอบใช้ provider fixtures เพื่อทดสอบราคา/ข้อผิดพลาด/โควตา/การคำนวณ **ยังไม่ได้ยืนยันผลกับบัญชี Finnhub จริงของคุณ** ต้องใส่ key แล้วตรวจสิทธิ์ข้อมูลอีกครั้ง

เอกสารต้นทาง: [Quote API](https://finnhub.io/docs/api/quote), [Official Finnhub client](https://github.com/Finnhub-Stock-API/finnhub-python)
