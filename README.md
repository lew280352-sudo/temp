# StockLens 0.9.2 — ข่าวบริษัทสหรัฐฯ / PWA

**อัปเดต AI ฟรี:** ใช้ GroqCloud/Qwen 3.8 27B เป็นตัวหลัก แล้ว fallback ไป Ollama/Qwen3 8B อัตโนมัติเมื่อออนไลน์ขัดข้องหรือโควตาหมด พร้อม structured output, แหล่งอ้างอิง และ cache อ่าน [คู่มือตั้งค่า AI](docs/LOCAL_AI.md)

เว็บแอปภาษาไทยโทนน้ำเงินหม่น สำหรับเลือกบริษัทและเว็บไซต์ที่อยากติดตาม ติดตั้งแบบ PWA ได้เมื่อเปิดผ่าน HTTPS (localhost ใช้ทดสอบบนคอมได้) ระบบไม่ขอและไม่เก็บจำนวนหุ้น ต้นทุน หรือมูลค่าพอร์ต

**สถานะ:** ระบบบัญชีรองรับรหัส 6 หลักทางอีเมลหลังกรอกรหัสผ่านเมื่อเชื่อม SMTP และเปิดใช้ใน `.env`; บัญชีที่เคยเปิด Authenticator ยังใช้ต่อได้ ข่าว RSS บริษัท 4 แห่ง ข่าวเศรษฐกิจจาก Federal Reserve ข่าวสื่อการเงินผ่าน Finnhub สำหรับ 36 บริษัท และ AI สรุปข่าวใช้งานแล้ว มีกราฟรายสัปดาห์และ backtest เมื่อเพิ่ม Alpha Vantage key ฟรี Web Push ต้องมีเบราว์เซอร์ที่รองรับและเซิร์ฟเวอร์เปิดอยู่ ยังไม่มี SMTP ของแอปและโฮสต์ HTTPS ถาวร

## เปิดใช้งาน

ต้องมี Node.js 24+ และอินเทอร์เน็ตสำหรับติดตั้งแพ็กเกจและดึงข่าว ไม่ต้องสมัคร API เพื่ออ่าน 4 ฟีดบริษัท

```powershell
git clone https://github.com/lew280352-sudo/temp.git
cd temp
npm.cmd ci
npm.cmd start
```

เปิด **http://127.0.0.1:4173** สมัครสมาชิก เก็บรหัสกู้คืน แล้ว Login บน macOS/Linux ใช้ `npm` แทน `npm.cmd` หลังติดตั้งแพ็กเกจแล้ว Windows เปิด `start-stocklens.cmd` ได้เช่นกัน ต้องเปิดเซิร์ฟเวอร์ค้างไว้

หากมีโปรเจกต์เดิมแล้ว ให้รันจากโฟลเดอร์ `stocklens` และสำรองข้อมูลก่อนอัปเดต `.data/stocklens.sqlite` ยังคงใช้เดิม เมื่อเริ่มเวอร์ชัน 0.5 ครั้งแรก ระบบจะเก็บเฉพาะ ticker สหรัฐฯ ที่รองรับเป็นรายการติดตามและลบจำนวนหุ้น/ต้นทุนเดิมออกจาก state

## สิ่งที่ทำงานแล้ว

- Register / Login / Logout, รหัสผ่าน hash ด้วย scrypt และ session cookie แบบ HttpOnly
- รหัสกู้คืนแบบใช้ครั้งเดียว เก็บเฉพาะ hash ฝั่งเซิร์ฟเวอร์ กู้บัญชีแล้วออกจากระบบทุกอุปกรณ์
- รหัสอีเมลแบบใช้ครั้งเดียวหลังรหัสผ่านเมื่อมี SMTP และเปิด `EMAIL_LOGIN_OTP_ENABLED=true`; Authenticator เดิมยังใช้ได้จนเจ้าของบัญชีปิดเอง; ลบบัญชีพร้อมเพิกถอนทุกเซสชัน
- รายการบริษัทที่อยากติดตามแยกบัญชี เพิ่ม/นำออกได้โดยไม่ถามข้อมูลการถือหุ้น
- ค้นหา 36 บริษัทที่จดทะเบียนในสหรัฐฯ ด้วย ticker ชื่ออังกฤษหรือไทย พร้อมลิงก์นักลงทุนสัมพันธ์และ SEC EDGAR; แสดงไอคอนเว็บไซต์ทางการที่เก็บไว้ในแอป 33 บริษัท และตัวย่อสำหรับ 3 บริษัทที่ไม่มีไฟล์ใช้ได้
- ค้นชื่อบริษัทหรือตัวย่อผ่าน Finnhub เลือกบริษัทและช่วงย้อนหลัง 1, 3 หรือ 6 เดือน แล้วให้ AI สรุปหัวข้อข่าวที่พบพร้อมลิงก์ต้นทาง ใช้ Finnhub key และ Groq/Ollama ที่ตั้งค่าไว้ ผลข่าวเป็นตัวอย่างที่คัดจากผลค้น ไม่ใช่ทุกข่าวในช่วงนั้น
- กรอกคำค้นอิสระเพื่อเปิด Google News หรือ Bing News ในแท็บใหม่ได้โดยไม่ต้องมี API key; ผลค้นเว็บภายนอกไม่ถูกส่งเข้า AI ของแอป
- ดึงหัวข้อข่าวจริงจาก Apple, Microsoft, NVIDIA และ Netflix ทุก 15 นาที และข่าวการเงินของ 36 บริษัทผ่าน Finnhub เมื่อมี key; คัดให้เห็นหลายสำนักพร้อมชื่อผู้เผยแพร่ ลิงก์ เวลา และสถานะ
- กรองข่าวตามบริษัทที่ติดตามและแหล่งข่าวที่เปิดไว้ เพิ่มฟีด Federal Reserve ที่ตรวจสอบแล้วเพื่อดึง RSS จริงได้; URL อื่นที่เพิ่มเองเป็นบุ๊กมาร์ก
- สรุปหัวข้อข่าวด้วย Groq/Qwen 3.8 27B ออนไลน์ หรือ Ollama/Qwen3 8B ในเครื่อง พร้อมข้อจำกัด ความมั่นใจ และลิงก์ต้นฉบับ
- โหมดแนวโน้มสัปดาห์ถัดไปจากราคาปิดรายสัปดาห์ที่ปรับ split/ปันผลจาก Alpha Vantage พร้อมผลทดสอบย้อนหลัง 5 ปีและเทียบ baseline; งดสัญญาณเมื่อข้อมูล/ผลทดสอบยังไม่พอ และแสดงแนวโน้มที่เกิดขึ้นแล้วแยกต่างหาก
- กราฟราคาปิดรายสัปดาห์ที่จบแล้วสูงสุด 104 สัปดาห์ และ Web Push ข่าวใหม่สำหรับอุปกรณ์ที่อนุญาตขณะเซิร์ฟเวอร์ทำงาน
- PWA manifest, ไอคอน และหน้าออฟไลน์ ติดตั้งผ่านเมนูของเบราว์เซอร์ ไม่แคชข้อมูลบัญชีหรือ preferences
- ส่งออกบัญชี JSON, สำรองฐานข้อมูล, ชุดทดสอบ 20 ผู้ใช้ และไฟล์ Docker สำหรับเตรียมโฮสต์

ราคาจาก API แสดงพร้อมเวลาและป้ายข้อมูลเก่า ไม่มีการคำนวณมูลค่าพอร์ตหรือกำไรขาดทุน โมเดลแนวโน้มเป็นการทดลอง ไม่ใช่ผลทำนายจาก Groq และไม่รับประกันผล Custom GPT ยังไม่ได้เชื่อมต่อ อ่าน [ขั้นตอนเพิ่ม key และข้อจำกัด](docs/KNOWN_LIMITATIONS.md)

บนเครื่องเดิมรัน `node scripts/configure-mfa.mjs` และ `node scripts/configure-push.mjs` ครั้งเดียวเพื่อสร้างคีย์ลับใน `.env` ที่ Git ไม่ติดตาม แล้ว restart แอป เก็บคีย์ MFA และ VAPID คู่กับฐานข้อมูลเมื่อสำรองหรือย้ายเครื่อง ไม่มีค่าใช้จ่ายสำหรับตัวคีย์ แต่การเปิดให้มือถือภายนอกใช้ Push ต้องมีเซิร์ฟเวอร์ที่ทำงานต่อเนื่องและ HTTPS; การยืนยันอีเมลต้องมีบัญชี SMTP ของคุณเอง

หากต้องการรหัสอีเมลตอน Login ให้อ่าน [ขั้นตอนตั้ง SMTP และเปิดรหัสอีเมล](docs/USER_GUIDE.md#รหัสอีเมลหลังกรอกรหัสผ่าน) ก่อน ขณะ `EMAIL_LOGIN_OTP_ENABLED=false` แอปยังไม่ส่งรหัส Login จริง

## นำขึ้นออนไลน์

เปิดทดสอบจากมือถือภายนอกได้ชั่วคราวด้วย Cloudflare Quick Tunnel แบบ HTTPS และ OTP ทางอีเมล ลิงก์ปัจจุบันกับ PID อยู่ใน `.data/mobile-preview.json` บนเครื่องนี้ ลิงก์เปลี่ยนเมื่อเริ่ม tunnel ใหม่และใช้ไม่ได้เมื่อคอมหรือ tunnel หยุด ยังไม่มีโฮสต์ถาวรหรือบัญชีบริการเสียเงิน ดู [วิธีใช้และข้อจำกัด](docs/OPERATIONS.md)

GitHub เก็บซอร์สโค้ดเท่านั้น GitHub Pages รัน backend นี้ไม่ได้ หากต้องการ URL ถาวรต้องมีโฮสต์ Node.js 24+ หรือ Docker แบบ single instance, persistent disk และ HTTPS โดยตั้ง `APP_ORIGIN` ให้ตรง URL จริง

ที่มาของข้อกำหนดการติดตั้ง: [MDN — Making PWAs installable](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)
