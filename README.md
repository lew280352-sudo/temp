# StockLens 0.4.0 — US PWA

**อัปเดต AI ฟรี:** เพิ่ม Ollama + Qwen3 8B สำหรับสรุปหัวข้อข่าวในเครื่อง พร้อมแหล่งอ้างอิงและ cache ไม่ต้องมี AI API key อ่าน [คู่มือติดตั้ง Local AI](docs/LOCAL_AI.md) ราคาหุ้นยังใช้ Finnhub ตาม [FREE_SETUP.md](docs/FREE_SETUP.md)

เว็บแอปภาษาไทยโทนน้ำเงินหม่น สำหรับข่าวบริษัทสหรัฐฯ และพอร์ตส่วนตัว ติดตั้งแบบ PWA ได้เมื่อเปิดผ่าน HTTPS (localhost ใช้ทดสอบบนคอมได้)

**สถานะ:** ระบบบัญชี พอร์ต การกู้บัญชี การดึง RSS และ AI สรุปข่าวในเครื่องใช้งานผ่านเซิร์ฟเวอร์ Node.js แล้ว ยังไม่ได้เผยแพร่บนอินเทอร์เน็ต ราคาหุ้นต้องตั้งค่า key และ Push ขณะปิดแอปยังไม่เปิดใช้

## เปิดใช้งาน

ต้องมี Node.js 24+ และอินเทอร์เน็ตสำหรับติดตั้งแพ็กเกจและดึงข่าว ไม่ต้องสมัคร API เพื่ออ่าน 3 ฟีดบริษัท

```powershell
git clone https://github.com/lew280352-sudo/temp.git
cd temp
npm.cmd ci
npm.cmd start
```

เปิด **http://127.0.0.1:4173** สมัครสมาชิก เก็บรหัสกู้คืน แล้ว Login บน macOS/Linux ใช้ `npm` แทน `npm.cmd` หลังติดตั้งแพ็กเกจแล้ว Windows เปิด `start-stocklens.cmd` ได้เช่นกัน ต้องเปิดเซิร์ฟเวอร์ค้างไว้

หากมีโปรเจกต์เดิมแล้ว ให้รันจากโฟลเดอร์ `stocklens` และสำรองข้อมูลก่อนอัปเดต `.data/stocklens.sqlite` ยังคงใช้เดิม หุ้นไทยเดิมแสดงต้นทุน THB แยกจาก USD และไปหน้าแหล่งข้อมูลเพื่อเพิ่มฟีดสหรัฐฯ ได้

## สิ่งที่ทำงานแล้ว

- Register / Login / Logout, รหัสผ่าน hash ด้วย scrypt และ session cookie แบบ HttpOnly
- รหัสกู้คืนแบบใช้ครั้งเดียว เก็บเฉพาะ hash ฝั่งเซิร์ฟเวอร์ กู้บัญชีแล้วออกจากระบบทุกอุปกรณ์
- พอร์ตแยกบัญชี เพิ่ม/แก้/ลบหุ้น รองรับเศษหุ้น 6 ตำแหน่ง และต้นทุนเฉลี่ยถ่วงน้ำหนัก
- ค้นหา 12 บริษัทสหรัฐฯ ด้วย ticker ชื่ออังกฤษหรือไทย พร้อมลิงก์นักลงทุนสัมพันธ์และ SEC EDGAR
- ดึงหัวข้อข่าวจริงจาก Apple, Microsoft และ NVIDIA ทุก 15 นาทีเมื่อเซิร์ฟเวอร์ทำงาน เก็บใน SQLite พร้อมเวลาและสถานะข้อผิดพลาด
- กรองข่าวตามพอร์ตและแหล่งข่าวที่เปิดไว้ URL อื่นที่เพิ่มเองเป็นบุ๊กมาร์ก
- สรุปหัวข้อข่าวด้วย Qwen3 8B ผ่าน Ollama ในเครื่อง พร้อมข้อจำกัด ความมั่นใจ และลิงก์ต้นฉบับ
- PWA manifest, ไอคอน, ปุ่ม/วิธีติดตั้ง และหน้าออฟไลน์ ไม่แคชข้อมูลบัญชีหรือพอร์ต
- ส่งออกบัญชี JSON, สำรองฐานข้อมูล, ชุดทดสอบ 20 ผู้ใช้ และไฟล์ Docker สำหรับเตรียมโฮสต์

ต้นทุนเป็นข้อมูลที่ผู้ใช้กรอก ส่วนมูลค่า/กำไรขาดทุนประเมินจะแสดงเมื่อมีราคาจาก API ครบ พร้อมเวลาและป้ายข้อมูลเก่า ไม่แสดงผลทำนายหรือราคาจำลอง Custom GPT ยังไม่ได้เชื่อมต่อ แต่ใช้ Local AI ฟรีแทนได้

## ตรวจสอบ

```powershell
npm.cmd test
npm.cmd run test:ui
npm.cmd run test:pwa

```
